# agents

Agent 的提示词、技能（skill）与配置。目标：让同一类任务第二次做得比第一次快。

## 目录

```
agents/
├── prompts/    # 可复用的系统提示词 / 角色设定
├── skills/     # 技能包（一个技能一个目录，含 SKILL.md）
└── notes/      # 踩坑与调参记录
```

> 当前为空骨架，按实际使用逐步补充。

## 约定

- 提示词只写“稳定不变”的部分；一次性的任务细节放工作流里。
- 技能必须写明：何时触发、需要什么输入、产出什么、常见失败。
- 不把密钥、账号、客户数据写进仓库；用环境变量或本地未跟踪文件。
- 改动过的内置技能放独立目录做覆盖版本，并注明原因。
