# ai-automation-tools

AI 自动化工具集：把重复劳动固化成可复用的脚本、工作流与 Agent 能力。

## 目标

- **能脚本化的不手工做**：一次性操作沉淀为可重复执行的脚本。
- **能验证的再交付**：每个工具都带最小可运行示例。
- **小而专**：一个工具解决一个问题，组合起来完成复杂任务。

## 目录结构

```
.
├── scripts/      # 命令行脚本与自动化小工具
├── workflows/    # 可编排的自动化流程
├── agents/       # Agent 提示词、技能与配置
└── docs/         # 使用说明与踩坑记录
```

> 目录会随实践逐步补充，当前为规划骨架。

## 使用

各工具的使用方式见对应目录下的 README。通用约定：

1. 优先使用跨平台脚本（Python / Node.js）。
2. 敏感信息通过环境变量传入，不写入仓库。
3. 破坏性操作必须先确认目标路径。
