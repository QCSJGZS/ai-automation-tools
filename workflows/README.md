# workflows

把多个脚本/接口编排成一条可重复执行的流程。每个流程一个文件或一个子目录，内容包含：目标、触发条件、步骤、失败处理、验证方法。

## 约定

- 命名：`<动词>-<对象>`，例如 `batch-dxf-report.md`、`sync-invoice-to-sheet.md`。
- 每个流程必须能回答三个问题：**输入从哪来、中间失败怎么办、怎么确认成功**。
- 涉及外部发送（邮件、消息、发布）的步骤，默认人工确认后才执行。
- 能固化成脚本的步骤写进 `scripts/`，流程文件只保留编排与判断。

## 模板

```markdown
# <流程名>

## 目标
一句话说明这个流程解决什么问题。

## 输入
- 数据/文件来源、格式、数量级

## 步骤
1. 运行 `python scripts/xxx.py ...`
2. 检查输出中的 xxx
3. ……

## 失败处理
- 常见失败现象 → 对应处理

## 验证
- 如何确认这次跑对了（期望值、抽样检查）
```

> 暂无正式流程，待第一个真实需求落地后补充。
